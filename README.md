# Data Utilities

A small Java 17 library of reusable collection and text helpers.

## Features
- Remove duplicates while preserving encounter order.
- Find the second-largest distinct integer.
- Normalize whitespace in text.
- Explicit null handling and clear return values for missing results.

## Run
`mvn test`

JUnit 5 tests cover normal inputs, empty inputs, duplicate values, negative numbers, null arguments, and whitespace boundaries.
